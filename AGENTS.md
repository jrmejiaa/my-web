# AGENTS.md

Concise orientation for AI agents working in this codebase.

## Project Overview

Personal blog and portfolio for Jairo R. Mejia Aponte, an Embedded Software Engineer, branded as
"Oops I bug it again · J. Mejia". Built with Docusaurus 3.9.2 (React 18, JavaScript — no TypeScript),
hosted on Firebase. Dark mode default, blue/dark-blue palette, JetBrains Mono headings, Source Sans 3
body. Content focuses on Yocto, embedded Linux, and embedded systems.

## Architecture

**Rendering:** `docusaurus.config.js` wires `preset-classic` (blog + docs + pages + theme). Custom CSS
loads in cascade order: `variables.css` → `fonts.css` → `custom.css`, so tokens are defined before use.

**CSS layer order:**

1. `variables.css` — design tokens, overrides Infima `--ifm-*` variables
2. `fonts.css` — Google Fonts `@import`
3. `custom.css` — component-level overrides, navbar responsive trick, footer styles

**Swizzled components** (wrap originals, do not fork them):

- `src/theme/BlogPostItem/` — appends `<GiscusComponent />` when `frontMatter.enableComments === true`
- `src/theme/DocItem/Layout/` — appends `<GiscusComponent />` unconditionally on every doc page

## Key Entry Points

Read these first for any task:

1. `docusaurus.config.js` — navbar, footer, presets, Giscus plugin, color mode defaults
2. `src/css/variables.css` — all design tokens
3. `src/pages/index.js` — landing page: `FEATURED_POSTS`, `SKILLS` data arrays, component composition
4. `src/components/GiscusComponent/index.js` — comment widget, color-mode integration
5. `sidebars.js` — sidebar definitions (`codingSidebar` manual, `linuxSidebar`/`yoctoSidebar` auto)
6. `src/css/custom.css` — navbar responsive trick, footer overrides

## Content Authoring

**Blog post:**

```
blog/YYYY-MM-DD-slug/
└── index.md
```

```yaml
---
title: My Post Title
authors: jrmejiaa
tags: [yocto, linux]
enableComments: true   # omit to disable comments
---
```

**Doc page (yocto or linux):** drop a `.md` file into `docs/yocto/` or `docs/linux/` — autogenerated
sidebar picks it up automatically.

**Doc page (coding):** create the file under `docs/coding/`, then add its path to the relevant category
in `sidebars.js`.

## Repo-Specific Patterns

- **JavaScript with JSDoc** — all source files are `.js`. Do NOT create `.ts` or `.tsx` files.
  `@docusaurus/types` is installed only to power JSDoc `@type` annotations.

- **Navbar title trick** — the `title` in `docusaurus.config.js` is the full string for SEO/`<title>`.
  `custom.css` hides it with `font-size: 0` on `.navbar__title` and uses a `::after` pseudo-element
  to inject "Oops I bug it again · J. Mejia" on desktop and "J. Mejia" on mobile (`max-width: 768px`).

- **Giscus comments** — blog posts opt in via `enableComments: true` frontmatter; doc pages always
  have comments. `GiscusComponent` reads `useColorMode()` and passes `colorMode` directly as the
  Giscus `theme` prop (`'dark'` or `'light'`).

- **`HomepageFeatures` is unused** — `src/components/HomepageFeatures/` is a legacy scaffold artifact.
  Do not import it.

- **Firebase hosting** — deploy with `npm run build` then `firebase deploy --only hosting`.
  Project ID: `oops-i-bug-it-again`. This is not GitHub Pages.

## Design Tokens

All tokens live in `src/css/variables.css`. Key custom tokens:

**Palette:**

| Token                    | Purpose                          |
|--------------------------|----------------------------------|
| `--color-blue-light`     | `#4fc3f7` — accent highlights    |
| `--color-blue-mid`       | `#29b6f6` — primary interactive  |
| `--color-blue-dark`      | `#0288d1` — hover/pressed states |
| `--color-bg-primary`     | `#0d1117` — page background      |
| `--color-bg-secondary`   | `#161b22` — card/sidebar bg      |
| `--color-bg-tertiary`    | `#21262d` — elevated surfaces    |

**Terminal (TerminalHero):**

| Token                    | Purpose                          |
|--------------------------|----------------------------------|
| `--terminal-bg`          | Terminal background              |
| `--terminal-border`      | Terminal border                  |
| `--terminal-prompt`      | Prompt prefix color              |
| `--terminal-output`      | Output line color                |
| `--terminal-cursor`      | Blinking cursor                  |
| `--terminal-grid-color`  | Blue grid overlay in hero        |

**Typography:** `--ifm-font-family-base` (Source Sans 3), `--ifm-font-family-monospace` and
`--ifm-heading-font-family` (JetBrains Mono), `--ifm-font-size-base: 112%`.
