# Project conventions steering

Conventions to follow when working in this repository.

## ADRs

- Architecture Decision Records live in `adr/` at the repository root.
- Do **not** place ADRs under `docs/`. In this project `docs/` is the published Docusaurus content
  tree, so anything there renders as a public site page.
- Name ADRs `adr/NNNN-short-title.md` with a zero-padded incrementing number.
