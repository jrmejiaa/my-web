# Welcome on Linux corner

Welcome to my little Linux corner of tutorials! Here, I'll be sharing both basic and advanced topics I come across while working with Linux.

As you can imagine, all the cool hardware and driver-related stuff I find interesting will end up in the Kernel Space section. I’ll cover the basics, like how to create a new device under `/dev` that can be accessed from user space.

On the other side, in the User Space section, I’ll show you some tricks and tools I’ve found useful while building applications for final products.

The main focus here is Embedded Systems development—because that’s my jam. However, most of the content will still be useful if you're working with a regular Linux distro.
