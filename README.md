# Oops I bug it again · J. Mejia

Personal technical blog and portfolio for Jairo R. Mejia Aponte, an Embedded Software Engineer.
Covers Yocto, embedded Linux, and systems programming — built with Docusaurus 3.9.2 and hosted on Firebase.

## Description

In this website you will find all kind of interesting facts that I found in my journey as a Embedded Software 
Engineer. I will go deep into some basic knowledge of Linux and I use the industry-standard Yocto project as 
Build tool to compile customize Linux OS into known boards that you could buy like RBPi4.

You will find here basic knowledge that may exists already on internet but it is not easy to find or at least, 
it was not easy to find for me when I started as Junior in Belden Inc. Any of the information that you will 
find here is **not** proprietary in any way, I do have extra care to any information that it is vital for the 
companies that I work with.

All the code that you will find here could be used in your own projects as an starting point. I will love to 
here from you if any article or tutorial in this website was in any help, or if you want to discuss why I do 
think this would be the 'right' approach for certain problems that most of us have had when coding using Yocto.

This website is built using [Docusaurus](https://docusaurus.io/), a modern static website generator. 

## Features

- Animated terminal hero with typing effect
- Blog with per-post [Giscus](https://giscus.app) comments (GitHub Discussions)
- Docs across three sections: Yocto, Linux, and Programming
- Dark mode by default (blue/dark-blue palette, JetBrains Mono headings)
- Skills grid and career highlights on the landing and about pages

## Getting Started

**Prerequisites:** Node.js >= 18

```bash
npm install
npm start        # dev server at http://localhost:3000
npm run build    # production build → build/
```

## Deployment

Hosted on Firebase. After building:

```bash
firebase deploy --only hosting
```

Firebase project: `oops-i-bug-it-again` (configured in `.firebaserc`).

## Content

### Adding a blog post

1. Create `blog/YYYY-MM-DD-slug/index.md`
2. Add frontmatter:

    ```yaml
    ---
    title: My Post Title
    authors: jrmejiaa
    tags: [yocto, linux]
    enableComments: true
    ---
    ```

    Set `enableComments: true` to enable Giscus comments on that post.

### Adding a doc page

- **Yocto / Linux** — drop a `.md` file into `docs/yocto/` or `docs/linux/`; the sidebar updates automatically.
- **Coding** — add the file to `docs/coding/` and register it in `sidebars.js` under `codingSidebar`.

Comments are opt-in: set `enableComments: true` in a doc's frontmatter to show a Giscus thread.
Section `welcome-*` hub pages intentionally omit it.
